# Archimedes releases

Public release metadata for Archimedes installs: one file per product line, holding the latest version, its date, the sha256 of its download, the versions of the plugins it ships, and recent release headlines. Archimedes' Check for Updates reads it to tell an owner whether they are behind.

This repo holds no product files and no download links. Archimedes itself is private and is delivered by Place To Stand (placetostand.com).
